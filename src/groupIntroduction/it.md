IT班では、サークル内システムの開発や運用、オンプレサーバーの管理、Webサイトの開発などを行っています。完全初心者から経験者まで幅広く在籍しています。自由な雰囲気の中のびのびと活動できる環境を整えています。興味のある方はぜひ参加してください。3年次編入生も大歓迎です。

## 活動内容

- サークル内システムの開発/運用
- オンプレサーバーの管理/運用
- Discord Botの開発/運用
- Webサイトの開発/運用
- 技術勉強会
- 緩い定例会
- 雑談

## 技術スタック

- 言語
  - C#
  - JavaScript
  - TypeScript
- フレームワーク/ライブラリ
  - .NET
  - React
  - Next.js
  - Tailwind CSS
  - Discord.js
- データベース
  - PostgreSQL
  - SQLite
- インフラ
  - Docker/Docker Compose
  - Nginx
  - GitHub Actions
  - オンプレProxmox

## 活動場所

基本的にはDiscordのVCで活動しています。サークル内システムの開発や運用は、GitHubを使ってリモートで行っています。オンプレサーバーの管理や運用は、必要に応じてサーバーの設置場所に出向いて作業を行うこともあります。
